# A Corrida da Eficiência

Projeto da disciplina Projeto e Análise de Algoritmos.

## Algoritmos
- Busca Linear — O(n)
- Busca Binária — O(log n)
- Selection Sort — O(n²)
- Merge Sort — O(n log n)

## Execução
Requer Java 21.

```bash
javac TiposDeBusca.java
java ResultadosCompletos.csv
```

O programa executa cada cenário 4 vezes, descarta a primeira execução e calcula a média das 3 restantes.

## Saída
O CSV registra tempo médio, comparações médias e movimentos médios.
